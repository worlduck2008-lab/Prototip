# Ждём Мишу — APK через GitHub

1. Загрузите ВСЕ файлы этого архива в корень нового репозитория GitHub (папка `.github` обязательна).
2. Откройте Actions → Build APK (запустится сама или нажмите Run workflow).
3. Через 3–6 минут откройте раздел Releases справа на главной странице репозитория и скачайте `zhdem-mishu.apk`.
